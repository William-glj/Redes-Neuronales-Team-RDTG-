1. PUNTO NUMERO 1: EDA (Análisis Exploratorio de Datos)

Ciencia de Datos: Se refiere al Exploratory Data Analysis (EDA), un proceso fundamental para resumir las características principales de un dataset, detectar patrones, identificar anomalías y limpiar los datos antes de pasar a la fase de modelado con redes neuronales.

1.1. Carga de datos y limpieza inicial

En este paso importamos las librerías necesarias (pandas y numpy), realizamos la lectura del dataset original y ejecutamos el proceso de depuración de registros duplicados e inconsistentes.

import pandas as pd
import numpy as np

# 1. Cargamos los datos del dataset
df_original = pd.read_csv('TMBD Movie Dataset.csv')
print(f"Dimensiones iniciales: {df_original.shape[0]} filas, {df_original.shape[1]} columnas")

# Creación de una copia de trabajo
df = df_original.copy()

# 2. Eliminación de duplicados por ID (si existe la columna)
if 'id' in df.columns:
    filas_duplicadas = df.duplicated(subset=['id']).sum()
    if filas_duplicadas > 0:
        df = df.drop_duplicates(subset=['id'], keep='first')
        print(f"Se eliminaron {filas_duplicadas} filas duplicadas por ID.")
    else:
        print("No se encontraron duplicados.")

# 3. Filtrado de valores incoherentes en presupuesto y recaudación
if 'budget' in df.columns and 'revenue' in df.columns:
    budget_revenue = (df['budget'] > 10000) & (df['revenue'] > 10000)
    df_clean = df[budget_revenue].copy()
    filas_eliminadas = len(df) - len(df_clean)
    print(f"Se eliminaron {filas_eliminadas} filas con presupuesto/recaudación <= $10,000.")
else:
    df_clean = df.copy()

# 4. Imputación de nulos en duración (runtime)
if 'runtime' in df_clean.columns and df_clean['runtime'].isnull().sum() > 0:
    mediana_runtime = df_clean['runtime'].median()
    df_clean['runtime'] = df_clean['runtime'].fillna(mediana_runtime)
    print(f"Nulos en 'runtime' imputados con la mediana: {mediana_runtime} min.")

# 5. Formato de fechas e imputación de textos
if 'release_date' in df_clean.columns:
    df_clean['release_date'] = pd.to_datetime(df_clean['release_date'], errors='coerce')
    df_clean = df_clean.dropna(subset=['release_date'])

columnas_texto = [col for col in ['tagline', 'overview', 'homepage', 'genres', 'keywords'] if col in df_clean.columns]
for col in columnas_texto:
    df_clean[col] = df_clean[col].fillna('')

if 'budget' in df_clean.columns:
    df_clean['budget'] = df_clean['budget'].astype(int)
if 'revenue' in df_clean.columns:
    df_clean['revenue'] = df_clean['revenue'].astype(int)
if 'genres' in df_clean.columns:
    df_clean['genres'] = df_clean['genres'].astype(str).str.strip()

print(f"\nRESUMEN: {len(df_original)} registros iniciales -> {len(df_clean)} registros limpios finales.")
